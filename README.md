## Research Objective

Build a simple scorekeeping application in Swift/SwiftUI to develop proficiency with Xcode project structure, SwiftUI views, and unit testing.

## Process of Experimentation

### Approach 1: SwiftUI app with test suite
- **Hypothesis:** A simple app domain (scorekeeping) provides a low-risk environment to learn SwiftUI layout, state management, and XCTest.
- **Result:** SUCCEEDED as a learning exercise. The app builds and runs, with unit tests.
- **Disposition:** Skills learned here (Xcode project structure, SwiftUI, unit testing) transferred directly to the document editor work.
